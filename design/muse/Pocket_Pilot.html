Most apps help you earn points. Pocket Pilot makes sure you keep your money.

A credit-card copilot for college students juggling their first cards. It picks the card that costs the least — not the one with the flashiest points — and explains every call in plain words. This is the full UI design: a working prototype, every screen in light and dark, components, tokens, and motion notes for the Expo / React Native build.

Theme
State

Fully tappable: tab bar, card stack, Debt Guard, store picks, funding switch, alert actions and Coach chips all work. Nothing here charges anything — it’s a design prototype.

All five screens, both themes

Every screen is drawn from the same token set — only the token values change between light and dark. Card art is identical in both themes, like the physical cards it represents.

Loading, error & empty states

The three states every screen needs. Loading uses a shimmer skeleton in the real layout’s shape; the error state says plainly that nothing was paid; the empty state appears before a first card is linked.

Component sheet

The building blocks, rendered live from the same CSS the screens use — card, chip, usage bar, alert card, buttons, switch, chat bubble and ranked row, in both themes.

Design tokens

One token file drives both themes. Accent is a deep emerald (“money kept”), amber is reserved for warnings, and a soft red means interest or danger. Every text/background pair below meets WCAG AA.

Motion notes

Subtle and purposeful: 150–350ms, spring easing, and everything collapses to a short fade when the system “reduce motion” setting is on. Each note names the trigger, timing, and the React Native Reanimated approach.

Pocket Pilot — original concept UI. Card names, artwork and brand are fictional; no real bank, card network or app branding is used. Balances and figures are the design spec’s sample data. In-app data badge: “Live data · Capital One Nessie.”
